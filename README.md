# privacy-policy
1. 应用收集和传输的信息

DeepSeek API Key：你配置的密钥仅存储在本地 %LocalAppData% 目录，用于向 DeepSeek API 发起请求。

对话内容：你输入的文本会发送至 DeepSeek API（api.deepseek.com）以生成回复，同时保存在本地会话记录中。
上传的图片文件：你选择的图片会发送至 DeepSeek API 进行识别，同时本地会保存一份副本用于会话历史显示。

搜索查询：使用联网搜索时，查询词会发送至你配置的搜索 API 端点（如博查）。

会话记录与配置：全部存储在本地，不会上传至开发者服务器。

2. 明确声明“不收集”的内容

本应用不包含任何分析、追踪或广告 SDK。

开发者不会收集、上传或访问你的 API Key、对话内容或任何本地数据。

应用不要求注册账号，不收集设备标识符。

3. 第三方服务说明
 列出 DeepSeek API 和搜索 API 的隐私政策链接，说明数据由这些第三方服务处理。
DeepSeek：https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html;
博查搜索：https://open.bochaai.com/privacy-policy

5. 数据存储与删除

说明所有本地数据保存在 %LocalAppData%\DeepSeekChatClient\，你可以通过删除该文件夹或使用应用内的删除功能来清除数据。
